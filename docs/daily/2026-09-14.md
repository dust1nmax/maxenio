## 真正理解的知识

### 1. ChatModel 的 Generate 和 Stream 区别

- **Generate**: 一次性返回完整响应，通过 `response.Content` 获取
- **Stream**: 流式返回，需要用 `reader.Recv()` 循环获取 chunks

### 2. Prompt Template 的作用

Template 相当于"填空题"：
- 固定内容 + 动态变量 → 最终 Prompt
- 用 `template.Format(ctx, params)` 得到 `[]*schema.Message`

## 写过的代码

### Demo 1: 基础聊天 + Prompt Template

```go
template := prompt.FromMessages(
    schema.FString,
    schema.SystemMessage("你是一个{role}"),
    &schema.Message{
        Role:    schema.User,
        Content: "回答{task}",
    },
)

params := map[string]any{
    "role": "编程助手",
    "task": "golang的优势",
}

messages, err := template.Format(ctx, params)
response, err := model.Generate(ctx, messages)
```

### Demo 2: 流式输出

```go
reader, err := model.Stream(ctx, messages)
defer reader.Close()

for {
    chunk, err := reader.Recv()
    if err != nil {
        break
    }
    print(chunk.Content)
}
```

### Demo 3: 简单 Messages 聊天

```go
messages := []*schema.Message{
    schema.SystemMessage("你是一个助手"),
    schema.UserMessage("你是谁？"),
}

response, err := model.Generate(ctx, messages)
println(response.Content)
```
