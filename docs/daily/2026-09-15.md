## 真正理解的知识

### 1. Milvus 架构

Milvus 是一个向量数据库，核心组件：
- **etcd**：保存元数据
- **MinIO**：对象存储，保存持久化数据
- **Milvus Standalone**：提供向量数据库服务
- **Attu**：Web 可视化管理界面（不是数据库本身）

### 2. Docker 数据持久化

`docker compose down` 删除容器时，通过 Bind Mount 映射的数据仍然保留在宿主机 `volumes/` 目录。

### 3. Milvus 数据层级

```
Database → Collection → Field
MaxEino  → test       → id / vector / content / metadata
```

### 4. Embedding 与向量

```
文本 → Embedding → Vector (2048 维, []float64)
```

### 5. Eino milvus2 Indexer

作用：将 Document 转换并写入 Milvus

```
Document → Embedding → Vector → Indexer → Milvus
```

### 6. Indexer 与 RAG 的关系

- **Indexer**：写入知识库（Document → Milvus）
- **Retriever**：从知识库检索（Query → Milvus Search → Documents）

完整 RAG：
```
写入：Document → Embedding → Indexer → Milvus
读取：Query → Retriever → Milvus → Relevant Docs → LLM → Answer
```

### 7. Document 存储格式

存储到 Milvus 的格式是 `schema.Document`：

| 字段 | 说明 |
|------|------|
| ID | 文档唯一标识 |
| Content | 文本内容（自动转向量） |
| MetaData | 自定义元数据 |

Indexer 自动调用 Embedder 将 Content 转成向量，然后存入 Milvus。

### 8. milvus2 vs milvus（v1）

- **milvus**：旧版客户端
- **milvus2**：新版客户端（v2），Eino 使用 `github.com/cloudwego/eino-ext/components/indexer/milvus2`
